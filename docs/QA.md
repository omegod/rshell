# RShell 发布验收

以下检查需分别在 macOS arm64 和 Windows x64 上执行。测试账号应只拥有临时目录权限，不要使用生产服务器。

## 基线

- [ ] `pnpm install --frozen-lockfile` 成功
- [ ] `pnpm typecheck` 无错误
- [ ] `pnpm build` 成功
- [ ] 对应平台安装包可以生成、安装、启动和退出
- [ ] 启动后没有白屏或未处理的控制台错误

## 连接

- [ ] 新建、编辑、删除密码连接
- [ ] 新建、编辑、删除私钥连接
- [ ] 测试连接成功和失败均有明确反馈
- [ ] 重启应用后配置仍存在，配置文件中没有明文密码或 passphrase
- [ ] 同时打开三个会话并切换、关闭标签页
- [ ] 远端主动断开后界面进入断开状态

## 终端

- [ ] 输入、退格、方向键、Tab 和 Ctrl+C 正常
- [ ] 中文输入与 UTF-8 输出无乱码
- [ ] 复制、粘贴和链接打开正常
- [ ] `vim`、`top` 或 `htop` 的 ANSI 颜色和全屏刷新正常
- [ ] 调整窗口、侧栏宽度和字号后终端尺寸正确
- [ ] 连续输出大量文本时，输入和滚动无明显冻结
- [ ] Linux 远端状态栏持续更新且请求不重叠
- [ ] 非 Linux 远端显示监控不可用，不影响终端

## 文件

- [ ] 浏览 home、根目录、空目录和无权限目录
- [ ] 快速连续进入多个目录时不会显示旧目录内容
- [ ] 展开失败的目录后可以再次尝试
- [ ] 2000 个文件的目录可以滚动和选择
- [ ] 创建文件、创建目录、重命名和递归删除
- [ ] 上传、下载、进度显示和取消传输
- [ ] 取消或失败后不会保留误导性的完整文件
- [ ] Windows 本地路径中的文件名处理正确

## 编辑器与外观

- [ ] 双击文本文件打开编辑器并可保存
- [ ] 二进制文件和超过 5 MB 的文件被拒绝
- [ ] 未保存时关闭编辑器会要求确认
- [ ] 编辑期间切换或关闭其他 Session 不会写错服务器
- [ ] 浅色和深色主题下文字、边界、菜单与编辑器均清晰
- [ ] macOS 和 Windows 使用相同的应用布局与交互
